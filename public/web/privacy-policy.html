سياسة الخصوصية

شرح شامل لكيفية حماية بياناتك الشخصية في منصة Code Shell

ℹ️
1. مقدمة
مرحباً بك في منصة Code Shell التعليمية. نحن نلتزم بحماية خصوصية جميع المستخدمين وتوفير بيئة تعلم آمنة وموثوقة. باستخدامك للمنصة، فإنك توافق على سياسة الخصوصية الموضحة في هذه الصفحة.
📊
2. البيانات التي نقوم بجمعها
نقوم بجمع البيانات التالية لتقديم أفضل خدمة تعليمية: • المعلومات الشخصية: الاسم الأول، اسم الأب، اسم العائلة، وتاريخ الميلاد. • معلومات الاتصال: البريد الإلكتروني ورقم الهاتف. • البيانات التقنية: الدولة والعملة لضبط أسعار الكورسات والميزات. • بيانات الأداء والدراسة: تقدمك في الكورسات ونتائج الاختيارات والاختبارات.
❓
3. لماذا نجمع هذه البيانات؟
تُستخدم البيانات التي نجمعها للأغراض التالية: • إنشاء إشغال حسابك وتخصيص تجربة التعلم الخاصة بك. • متابعة تقدمك الدراسي وحفظ نتائجك بشكل آمن. • التواصل معك بشأن التحديثات والكورسات والخدمات الجديدة. • تحسين أمان المنصة ومنع الاستخدام غير المصرح به.
🔒
4. حماية البيانات والأمان
نتبع أعلى معايير الأمان لحماية بياناتك الشخصية من الوصول غير المصرح به أو التعديل أو الإفصاح. جميع الاتصالات والرموز البرمجية (Bearer Tokens) تشفر باستخدام بروتوكولات حماية متطورة وLaravel Sanctum.
👤
5. حقوق المستخدم
لديك الحق الكامل في: • الوصول إلى بياناتك الشخصية وتحديثها من خلال صفحة الإعدادات أو تعديل الملف الشخصي. • طلب تغيير كلمة المرور وتحديث البريد الإلكتروني. • طلب حذف حسابك نهائياً من المنصة متى أردت.
🍪
6. التخزين المحلي وملفات الكوكيز
نستخدم التخزين المحلي (LocalStorage) لحفظ الجلسة الآمنة والمظهر المفضل (فاتح/داكن) وتسريع استجابة المنصة أثناء استخدامك لها.
📧
7. التواصل معنا
إذا كانت لديك أي أسئلة أو استفسارات حول سياسة الخصوصية، يمكنك التواصل معنا عبر الدعم الفني أو عبر الواتساب المتاح في قسم "تواصل معنا".
🔄
8. آخر تحديث
تم آخر تحديث لسياسة الخصوصية بتاريخ سبتمبر 2026. يحتفظ فريق Code Shell بحق تعديل هذه السياسة عند الحاجة.
