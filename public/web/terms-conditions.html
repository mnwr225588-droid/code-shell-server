القواعد والبنود المنظمة لاستخدام منصة Code Shell التعليمية

ℹ️
1. مقدمة
مرحباً بك في منصة Code Shell. استخدامك للمنصة يعني موافقتك الكاملة على جميع الشروط والأحكام المحددة في هذه الصفحة. يرجى قراءتها بتمهل قبل البدء في استخدام الخدمات.
👤
2. إنشاء الحساب والأمان
• يجب تقديم بيانات شخصية دقيقة وصحيحة عند تسجيل الحساب (الاسم الكامل، بريد إلكتروني فعال، رقم الهاتف، وتاريخ الميلاد). • أنت مسؤول مسؤولية كاملة عن الحفاظ على سرية بيانات تسجيل الدخول وتغيير كلمة المرور بشكل دوري. • يمنع منعاً باتاً مشاركة الحساب الشخصي مع أي شخص آخر.
📱
3. استخدام المنصة والتطبيق
تلتزم باستخدام المنصة للأغراض التعليمية والشخصية فقط. يمنع استخدام أي وسيلة آلية أو برمجيات لإلحاق الضرر بالمنصة أو محاولة الوصول غير المصرح به لسيرفرات البيانات.
📖
4. المحتوى التعليمي والكورسات
جميع الكورسات والدروس والمواد المرئية المتاحة مخصصة للطلاب المشتركين فقط وفق الشروط المقررة للكورس (سواء كان مجانياً أو مدفوعاً).
©️
5. حقوق الملكية الفكرية
جميع حقوق الطبع والنشر والملكية الفكرية للمواد التعليمية والفيديوهات والتصميمات والرموز البرمجية محفوظة بالكامل لمنصة Code Shell. يمنع نسخ أو تصوير أو تسريب أو بيع أي محتوى دون إذن كتابي صريح من إدارة المنصة.
🚫
6. تعليق أو إلغاء الحساب
تحتفظ إدارة المنصة بحق تعليق أو إغلاق أي حساب يثبت انتهاكه لهذه الشروط والأحكام أو قيامه بسلوكيات تضر بالمنصة أو الطلاب الآخرين.
🛠️
7. الخدمات المستقبلية
تعمل منصة Code Shell باستمرار على إضافة ميزات جديدة وكورسات متطورة لتحديث وتطوير التجربة التعليمية.
✏️
8. تعديل الشروط والأحكام
يحق لمنصة Code Shell تعديل هذه الشروط في أي وقت. وتعتبر التعديلات نافذة فور نشرها على هذه الصفحة.
🎧
9. الدعم الفني
فريق الدعم الفني متواجد لمساعدتك وحل أي عقبات أو استفسارات أثناء رحلتك التعليمية على المنصة.
🔄
