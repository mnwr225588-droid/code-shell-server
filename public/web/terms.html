الشروط والأحكام واشراطات الاستخدام

يرجى قراءة هذه الشروط والأحكام بعناية قبل استخدام منصة كود شيل أو تعبئة المحفظة الإلكترونية.

📌 1. اتفاقية الشراء والاستخدام العام

مرحباً بكم في منصة Code Shell. باستخدامك للموقع أو تسجيلك في أي من الكورسات والخدمات البرمجية، فإنك توافق التزامك التام بكافة الشروط والأحكام المبينة في هذه الصفحة. تضمن المنصة تقديم محتوى تعليمي عالي الجودة ودعم فني مستمر لجميع الطلاب المسجلين.

💳 2. شروط وتعبئة محفظة كود شيل (Code Shell Wallet)

  • أقل مبلغ مسموح به لشحن المحفظة الإلكترونية هو 30 جنيه مصري (30 EGP).
  • يتم إضافة الرصيد إلى محفظتك فوراً بمجرد تأكيد وتوثيق عملية الدفع عبر بوابة EasyKash الإلكترونية.
  • يمكنك استخدام رصيد المحفظة للاشتراك في أي كورس برمجي متاح بالمنصة بسهولة وسرعة دون الحاجة لإعادة أدخال بيانات الدفع في كل مرة.
  • في حال إلغاء الاشتراك في أي كورس، يتم إعادة كامل المبلغ المسدد إلى محفظتك الإلكترونية تلقائياً ليمكنك استخدامه في دورات أخرى.

🛡️ 3. إلغاء الاشتراك والحفظ الأمني

تحتفظ منصة Code Shell بكافة حقوق الملكية الفكرية للمواد والمحاضرات البرمجية. يُحظر مشاركة الحسابات أو إعادة طباعة ونشر المحتوى دون إذن كتابي مسبق. يمكنك إلغاء الاشتراك في أي كورس في أي وقت مباشرة عبر حسابك دون الحاجة للرجوع إلى الدعم الفني.
